# Flash Multiplyer 完整版 · 安装说明

> 在 Windows 10/11 x64 + Microsoft Edge 上用真正的 Flash Player 内核（Adobe Flash Player 34）播放 Flash 内容。
> 不依赖 Ruffle 模拟器，兼容性最好，可以玩 4399、QQ 空间小游戏之类的老 Flash 游戏。

---

## 一、这个包里有什么

```
Flash Multiplyer 完整版\
├─ 安装.ps1              ← 运行这个来安装
├─ 卸载.ps1              ← 不想用了运行这个
├─ 安装说明.md           ← 本文件（中英双语）
├─ extension\            ← 浏览器扩展（Edge 里加载的就是这个文件夹）
│   ├─ manifest.json
│   ├─ content.js / page-script.js / background.js / i18n.js
│   └─ settings.html / settings.css / settings.js / icons\ ...
└─ host\
    ├─ flash-player-host.exe   ← 原生消息宿主（Rust 编译，8.4 MB）
    └─ pepflashplayer64.dll    ← 真正的 Adobe Flash Player 34 插件（15.3 MB）
```

三者关系：

```
Edge 页面 → 扩展（替换网页里的 Flash 标签、转发网络和 Cookie）
              → 原生消息宿主 flash-player-host.exe（真正的 PPAPI 宿主）
                    → pepflashplayer64.dll（Flash 渲染引擎）
```

**只装扩展是不够的**，必须跑安装脚本把宿主和插件装好。

---

## 二、系统要求

- Windows 10 / 11，64 位
- Microsoft Edge（Chromium 内核均可）、Chrome / Brave / Vivaldi / Opera 也能用
- 不需要管理员权限（脚本只写当前用户的环境：`HKCU` 注册表和 `%LOCALAPPDATA%`）
- 极少数精简版系统缺 `VCRUNTIME140.dll` 时需要装一下 [VC++ 2015-2022 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)

---

## 三、安装步骤

### 步骤 1：解压

把 `Flash Multiplyer 完整版.zip` 右键「全部解压缩」到任意位置（**不要**直接在压缩包里双击运行脚本，会找不到文件）。

### 步骤 2：运行安装脚本

进入解压出来的 `Flash Multiplyer 完整版` 文件夹：

- **方法 A**：右键 `安装.ps1` → **使用 PowerShell 运行**
- **方法 B**：在文件夹空白处 `Shift + 右键` → 「在此处打开 PowerShell 窗口」，然后输入：

  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装.ps1"
  ```

  如果提示「无法加载文件，因为在此系统上禁止运行脚本」，用上面这条带 `-ExecutionPolicy Bypass` 的命令即可。

脚本会做四件事（窗口里会逐步显示）：

1. 把宿主和插件复制到 `C:\Users\<你的用户名>\AppData\Local\FlashMultiplyer\`
2. 生成原生消息宿主清单 `org.cleanflash.flash_player.json`（UTF-8 **无 BOM**，带 BOM 会失效）
3. 在 `HKCU` 里为 Edge / Chrome / Chromium / Brave / Vivaldi / Opera 注册该宿主
4. 设置用户环境变量 `FLASH_PLUGIN_PATH`

看到「安装完成」后按回车关闭窗口。

> ⚠️ 注意：这里写的是 **HKCU**（当前用户），不是 HKLM（所有用户），所以不用管理员权限，也不需要 UAC 弹窗。

### 步骤 3：在 Edge 里加载扩展（必须手动，Edge 不允许自动装非商店扩展）

1. 打开 Edge。
2. 地址栏输入 **`edge://extensions`** 回车。
3. 页面**左下角**（老版本在右上角）找到 **「开发人员模式」** 开关，**打开它**。
4. 点击 **「加载解压缩的扩展」**（英文界面：`Load unpacked`）。
5. 在弹出的文件夹选择框里，定位到：

   ```
   C:\Users\<你的用户名>\AppData\Local\FlashMultiplyer\extension
   ```

   小技巧：直接在地址栏粘贴 `%LOCALAPPDATA%\FlashMultiplyer\extension` 回车即可跳转。
6. 选择成功后，扩展列表里会出现 **「Flash Multiplyer」** 卡片，版本 1.0.0。
7. 如果右上角弹出「关闭开发人员模式下的扩展」提示，**点 × 关掉即可**。

> 扩展的 ID 由 `manifest.json` 里的 `key` 决定，固定是
> `dcikaadaeajidejkoekdflmfdgeoldcb` — 所以换电脑、重新加载都不用改任何配置。

### 步骤 4：完全退出 Edge 再重新打开

**必须做**。原因：`FLASH_PLUGIN_PATH` 是用户环境变量，已经运行的 Edge 进程读不到新值（虽然宿主也会在自己目录找插件，但重启一次最稳妥）。

- 关闭所有 Edge 窗口
- 打开任务管理器（`Ctrl + Shift + Esc`）→ 找 `Microsoft Edge` → 有残留进程就右键「结束任务」
- 重新打开 Edge

### 步骤 5：验证

打开任意 Flash 网站（例如 `https://www.4399.com/` 的小游戏页），画面能显示、能玩就成功了。

## 四、日常使用

- **切换语言**：点 Edge 工具栏上的扩展图标 → 弹窗右上角 `中文 / English` 切换，默认中文，选择会记住。
- **设置项**：同一个弹窗里可调 Ruffle 兼容模式、网络请求方式、HTTP/TCP 沙箱、隐私项、硬件加速、音频后端、URL 重写等。
- **右键菜单**：页面里右键会多出「Flash Multiplyer Settings…」入口。

## 五、常见问题

### 1. 页面仍显示 “To view this page ensure that Adobe Flash Player version 10.0.0 or greater is installed.”

1. **宿主没起来**：任务管理器看有没有 `flash-player-host.exe`。没有 → 注册表没写对，检查
   `HKCU\Software\Microsoft\Edge\NativeMessagingHosts\org.cleanflash.flash_player`
   的默认值是否指向 `...\FlashMultiplyer\host\org.cleanflash.flash_player.json`；
   有但一闪而过 → 确认 `pepflashplayer64.dll` 和 `flash-player-host.exe` 在**同一目录**。
2. **清单带 BOM**：用记事本另存为 UTF-8 时容易带 BOM，重跑 `安装.ps1` 可覆盖修复。
3. **扩展没加载**：`edge://extensions` 里确认卡片是启用状态。
4. **Edge 没重启**：完全退出再打开。

### 2. 中文显示成方块 □

说明用的不是这个编译版宿主（原版把默认字体写死成 Arial，没有中文字形）。本包已将默认字体改为「微软雅黑」，正常不会出现方块。

### 3. 字太大 / 太小

字号编在宿主的 `crates/ppapi-host/src/font_rasterizer.rs`（`FONT_SCALE`，当前 1.22），要改需重新编译。

### 4. 想恢复原样

运行 `卸载.ps1`（删注册表项、环境变量，并询问是否删除安装目录），再在 `edge://extensions` 移除扩展。

---

## 六、安全说明

- 原生消息宿主只和上面那个固定 ID 的扩展通信（`allowed_origins` 白名单）。
- Flash 插件本体来自第三方维护的 Flash 34 中国版补丁包，**不是** Adobe 官方签名版本，请自行评估风险；建议只用来玩单机/怀旧游戏。
- 本包不联网、不上传任何数据；所有文件都在 `%LOCALAPPDATA%\FlashMultiplyer` 下，卸载即清空。

# Flash Multiplyer — Installation Guide (English)

> Play real Flash content in Microsoft Edge on Windows 10/11 x64, powered by the genuine Adobe Flash Player 34 plugin.
> Not a Ruffle emulator — native plugin, best compatibility with old Flash sites and games.

## 1. What's in the package

```
Flash Multiplyer 完整版\
├─ 安装.ps1              ← run this to install (Installer)
├─ 卸载.ps1              ← run this to uninstall
├─ 安装说明.md           ← this file (bilingual)
├─ extension\            ← the browser extension (load this folder in Edge)
│   ├─ manifest.json
│   ├─ content.js / page-script.js / background.js / i18n.js
│   └─ settings.html / settings.css / settings.js / icons\ ...
└─ host\
    ├─ flash-player-host.exe   ← native messaging host (Rust, 8.4 MB)
    └─ pepflashplayer64.dll    ← Adobe Flash Player 34 plugin (15.3 MB)
```

```
Edge page → extension (replaces Flash embeds, relays network and cookies)
             → native host flash-player-host.exe (PPAPI host)
                   → pepflashplayer64.dll (Flash engine)
```

**Installing only the extension is not enough** — the installer must set up the host and the plugin.

## 2. Requirements

- Windows 10 / 11, 64-bit
- Microsoft Edge (any Chromium browser also works: Chrome / Brave / Vivaldi / Opera)
- **No administrator rights required** — the script only writes `HKCU` and `%LOCALAPPDATA%`
- On minimal Windows images, install the [VC++ 2015-2022 Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) if `VCRUNTIME140.dll` is missing

## 3. Installation

### Step 1 — Extract

Right-click the zip → **Extract All**. Do **not** run the scripts from inside the archive.

### Step 2 — Run the installer

Inside the extracted `Flash Multiplyer 完整版` folder:

- **Option A**: right-click `安装.ps1` → **Run with PowerShell**
- **Option B**: `Shift + right-click` in the folder → *Open PowerShell window here*, then run:

  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File ".\安装.ps1"
  ```

The script will:

1. Copy the host and plugin to `C:\Users\<you>\AppData\Local\FlashMultiplyer\`
2. Write the native messaging host manifest (`org.cleanflash.flash_player.json`, UTF-8 **without BOM**)
3. Register the host for Edge / Chrome / Chromium / Brave / Vivaldi / Opera under `HKCU`
4. Set the user environment variable `FLASH_PLUGIN_PATH`

Press Enter when it reports success.

### Step 3 — Load the extension in Edge (manual, by design)

1. Open Edge
2. Go to **`edge://extensions`**
3. Turn on **Developer mode** (bottom-left on current versions)
4. Click **Load unpacked**
5. Select:

   ```
   C:\Users\<you>\AppData\Local\FlashMultiplyer\extension
   ```

   Tip: paste `%LOCALAPPDATA%\FlashMultiplyer\extension` into the folder dialog address bar.
6. The **“Flash Multiplyer”** card should appear (version 1.0.0)
7. Dismiss the “Turn off developer mode extensions” bubble — it does not affect functionality

> The extension ID is fixed by the `key` in `manifest.json`:
> `dcikaadaeajidejkoekdflmfdgeoldcb` — already whitelisted in the native host manifest.

### Step 4 — Fully restart Edge

Required, because `FLASH_PLUGIN_PATH` is only read by newly started processes.
Close every Edge window (check Task Manager for leftovers) and start it again.

### Step 5 — Verify

Open any Flash site (e.g. a mini-game on `https://www.4399.com/`). If it renders and plays, you are done.

## 4. Daily use

- **Language**: extension popup → `中文 / English` switch (default Chinese, remembered)
- **Settings**: Ruffle compatibility, network mode, HTTP/TCP sandboxing, privacy, hardware acceleration, audio backend, URL rewriting
- **Context menu**: “Flash Multiplyer Settings…” entry on pages

## 5. Troubleshooting

1. *“To view this page ensure that Adobe Flash Player version 10.0.0 or greater is installed.”*
   - Check `flash-player-host.exe` in Task Manager. Missing → verify the registry value
     `HKCU\Software\Microsoft\Edge\NativeMessagingHosts\org.cleanflash.flash_player` points to
     `...\FlashMultiplyer\host\org.cleanflash.flash_player.json`.
     Present but exiting immediately → `pepflashplayer64.dll` must sit **next to** the exe.
   - Manifest saved with a BOM by Notepad → re-run the installer.
   - Extension disabled → check `edge://extensions`.
   - Edge not restarted → restart it fully.
2. *Chinese characters render as `□`* — you are not running this build (upstream defaults to Arial). This package uses Microsoft YaHei.
3. *Text too large / too small* — `FONT_SCALE` in `crates/ppapi-host/src/font_rasterizer.rs` (currently 1.22); requires a rebuild.
4. *Uninstall* — run `卸载.ps1`, then remove the extension in `edge://extensions`.

## 6. Security notes

- The native host only accepts connections from the fixed extension ID (`allowed_origins`).
- The Flash plugin is a third-party patched build (not Adobe-signed). Use it for legacy/offline games only.
- Nothing is uploaded anywhere; everything lives under `%LOCALAPPDATA%\FlashMultiplyer` and is removed by the uninstaller.
